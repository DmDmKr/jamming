
## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
To fully use the functionality and send authorized requests, you need to set the data in **util/Spotify.js** (your **clientId** and **userId**). You will be asked to log in to your Spotify account when running the app for the first time.
